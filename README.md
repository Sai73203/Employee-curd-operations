Employee Management System

A full-stack Employee Management System built using Spring Boot, Angular, and MySQL. This application enables organizations to manage employee records efficiently through a modern web interface and RESTful APIs.

📌 Project Overview:

The Employee Management System is designed to streamline employee data management by providing a centralized platform for performing CRUD (Create, Read, Update, Delete) operations. The frontend is developed using Angular, while the backend is powered by Spring Boot and connected to a MySQL database.

🚀 Features:
Add New Employees
View Employee List
View Employee Details
Update Employee Information
Delete Employee Records
RESTful API Integration
MySQL Database Connectivity
Layered Architecture Implementation

Responsive Angular UI
